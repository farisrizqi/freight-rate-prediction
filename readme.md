# Freight Rate Prediction — Spotter ML Engineer Assessment

Predicts freight `posted_rate` for 12,000 loads (Nov–Dec) using 48,000 labeled loads
(Jan–Oct) as training data.

## Approach summary

- **EDA:** `distance` is the dominant driver of rate (~0.9 correlation). Validation is a
  future time window (Nov–Dec), not a random sample, and contains 8 pickup/delivery
  cities never seen in training.
- **Data quality:** ~300 negative `weight` values were a sign error (range matches the
  positive values exactly) — fixed with `abs()`. `weight` and `market_index` have
  independent missing values — imputed with the **training-only** median plus a
  `*_was_missing` flag.
- **Features:** city names are dropped in favor of `pickup/delivery` latitude & longitude
  (fixed per city, so they generalize to unseen cities), plus `month`, `day_of_week`, and
  one-hot encoded `equipment`.
- **Model:** LightGBM outperformed XGBoost on default settings. Because RMSE was much
  higher than MAE (pointing to a handful of far-off predictions), an L1 (MAE) objective
  was compared against a log-transformed target and Huber loss — L1 gave the best MAE/MAPE.
  The remaining outliers were checked against every available feature and found to be
  unrelated to any of them (unexplainable noise, not a model or feature gap).
- **Split & validation:** time-based holdout — the last 6 weeks of the labeled data
  (2025‑09‑15 to 2025‑10‑31) are held out to mimic forecasting into an unseen future
  period. The final model is retrained on **all** labeled data before predicting on
  `data/validation.csv`.

Full reasoning, EDA, and diagnostic checks (including the ablation test explaining the
weekly pattern in the December predictions) are in the notebook.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run instructions

1. Make sure `data/train-test.csv`, `data/validation.csv`,
   `input/validation-predictions-template.csv`, and `input/december-chart-inputs.csv`
   are in place.
2. Launch Jupyter and run the notebook top to bottom:
   ```bash
   jupyter notebook notebook/freight_rate_prediction.ipynb
   ```
3. The notebook writes two files into `outputs/`:
   - `validation-predictions.csv` — `load_id,predicted_rate` for all 12,000 loads
   - `result-december-chart-inputs.csv` — December chart inputs with `predicted_rate` filled in
4. Score the outputs with `score.py` as instructed in the assessment brief.
